# 光谱与良率分析工作台

滤光片烘烤/清洗光谱对比 · 一体机良率分析 · 双规格一致性（EXP / AIR）判定。

单文件应用，打开即用，所有计算在浏览器本地完成，不上传任何测试数据。

## 打开

https://wx995.github.io/workbench/

## 功能

- **光谱对比分析**：多阶段曲线叠加、归零对齐、规格线、缩放/平移、均值腔位、异常排除
- **良率分析**：总体良率（1HT 及以后 / 1HT）、工单 T/G、炉号 × 一体机热力图
- **趋势专题**：炉次趋势、维度对比
- **双规格一致性**：按 S2（EXP）/ S2-OSA（AIR）逐腔位对比
  - 判定采用「读数据 2.57」写出的汇总文件结果（-S2.xls / -S2-OSA.xls），与软件一致
  - 曲线、参数来自原始测试文件，可点腔位查看 EXP / AIR 两条曲线
  - 支持按参数忽略（ISO / Ripple / MaxIL / ΔCW / 通带宽度）做模拟
  - 测试异常自动排除：通带整体塌陷、两边高中间塌等测量异常
- **良率看板**：四个默认 PN，最近 7 天 vs 前 7 天；1HT 良率、1HT 后良率、NG 率、波长长率（0263 不考核）、重测率
- **图表导出**：选图后导出 ZIP / HTML / PPT

## 本地使用

直接双击 `index.html`，或用任意静态服务器：

```bash
python -m http.server 8000
# 打开 http://127.0.0.1:8000/
```

## 更新

把新版工作台（`光谱与良率分析工作台(N).html`）放到 `D:\Desktop\数据处理\`，然后：

```powershell
.\publish.ps1
```

脚本会自动取最新版本、复制为 `index.html`、提交并推送。GitHub Pages 约 1 分钟后生效。

## 注意

- 浏览器只读取你选择的本地文件，不做上传。
- 建议 Chrome / Edge 最新版。
